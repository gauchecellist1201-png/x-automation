# Claude Codeで変わった私の研究スタイル

医学生がコードを書く時代になった。

Claude Codeを使い始めて3ヶ月、研究データの解析、論文サーベイの自動化、
PHRシステムのプロトタイピングが自分一人でできるようになった。

以前は「プログラマーに頼む」のが当たり前だった医療研究のコード部分が、
AIエージェントによって民主化された。

これが意味すること——
医師・医学生・看護師が「コードを書かずに」医療プロダクトを作れる時代が来た。
技術の壁が消えたとき、残るのは「何を作るか」というビジョンだけだ。

あなたの専門性をAIで拡張するとしたら、最初に自動化したいのは何か？
