# Claude Codeと医療AI：コードなしで医療を変える時代

Claude CodeのARRが9ヶ月で2,500億円を突破した。

この数字が示すのは単なるAIツールの普及ではない。
「専門家がコードを書かずにプロダクトを作れる時代」の到来だ。

医学生の私がClaude Codeを使い始めて気づいたこと：
プログラミング知識がなくても、医療データ分析ツールが数時間で作れる。

従来なら開発者と数週間かけて作るものが、今は医師・医学生が直接構築できる。

PHR（個人健康記録）×ブロックチェーンの実装も、以前は難しかった。
今は構想から実装まで、驚くほど短い時間でできる。

医療DXの障壁は「技術」ではなく「誰が作るか」だった。
AIはその答えを「医療を知る人が作る」に変えつつある。

医師・医学生がコードを書く時代が来た。
これは医療変革の静かな起点になると思っている。
