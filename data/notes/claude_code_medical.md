# Claude Codeで医療プロダクトを作った話：コードが書けない医学生が変わった日

半年前、私はコードが書けなかった。

プログラミングスクールに通うことも考えたが、医学部の勉強と並行させるのは現実的でなかった。

転機はClaude Codeとの出会いだ。

「やりたいことを日本語で伝えると、コードを書いてくれる」。それだけのことが、私の世界を変えた。

最初のプロダクト：PHR（個人健康記録）の簡易アプリ。ブロックチェーンと組み合わせて、患者が自分の医療データを管理できる仕組み。

開発期間：週末3回、合計約10時間。

以前なら半年かかっていたかもしれない作業が、AIとの対話で一気に形になった。

これが「AIによる民主化」の実体験だ。

医師・医学生がコードを書かずに医療プロダクトを作れる時代。これは医療変革の起点になる。技術者でなくても、課題を持つ医療者がシステムを設計できる時代が来た。

ただし重要なのは、AIは「実装ツール」であって「課題発見ツール」ではないことだ。どんな課題を解くかを決めるのは、引き続き人間でなければならない。
